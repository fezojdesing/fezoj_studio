Loreny
una identidad que se reconoce.

Branding / Dirección visual / Aplicaciones

Desarrollo de identidad visual para una cafetería, con un sistema gráfico llevado a producto y comunicación para mantener consistencia en distintos soportes.

Un sistema, no solo un logo.

La identidad se construye a partir de una tipografía definida, una paleta cromática y aplicaciones que permiten reconocer la marca tanto en producto como en comunicación.

El objetivo es que cada soporte se sienta parte de la misma marca.
